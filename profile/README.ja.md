## OpenStack の新しい体験を、一緒に

Afterglow は、OpenStack ダッシュボードと関連サービスを開発・管理するオープンソース組織です。中心となる Afterglow は、Horizon と Skyline に代わる、ユーザーと運用者のための現代的な統合ダッシュボードを目指しています。

[DMS Cloud](https://cloud.dmslab.re.kr) のコンソールとして運用されており、実際のクラウド運用から得た知見を改善に活かしています。サービスへのアクセスには、運用者のアカウント・プロジェクトポリシーが適用されます。

## プロジェクト

| プロジェクト | 役割 |
| --- | --- |
| [Afterglow](https://github.com/openstack-afterglow/openstack-afterglow) | SvelteKit と FastAPI による OpenStack リソース管理とサービス統合 |
| [Drover](https://github.com/openstack-afterglow/drover) | OpenStack 上の K3s クラスターとノードグループのライフサイクル管理 |
| [Palimpsest](https://github.com/openstack-afterglow/palimpsest) | 再利用可能な VM 環境、SquashFS レイヤー、ブートイメージ |
| [Lumen](https://github.com/openstack-afterglow/lumen) | AI チャット、エージェント実行、ツール、メモリー、使用量管理 |
| [Waygate](https://github.com/openstack-afterglow/waygate) | プロジェクトごとの WireGuard ゲートウェイとクライアント設定 |

各リポジトリの README で、セットアップ、対応環境、リリース状況、ライセンスを確認してください。コンポーネントごとに成熟度やデプロイ状況は異なります。

## 参加する

開発者、運用者、研究者、デザイナー、ドキュメント執筆者、初めての貢献者を歓迎します。コード以外にも、アクセシビリティ、翻訳、テスト、バグの再現、運用上のフィードバックで参加できます。

1. 関心のあるリポジトリの README、アーキテクチャ、開発指針を読みます。
2. 既存の Issue と PR を確認し、大きな変更は先に Issue で相談します。
3. Fork して作業ブランチを作成し、小さな変更にまとめます。指定されたチェックを実行し、必要なテストと文書を更新します。
4. 問題、変更内容、検証結果を説明する PR を提出します。UI 変更にはスクリーンショットを添えてください。

バグ報告にはバージョンまたはコミット、環境、期待した動作、実際の動作、最小限の再現手順を含めてください。認証情報や利用者データは削除してください。組織への加入なしで Issue や PR を提出できます。

相談先に迷ったら [Afterglow Issues](https://github.com/openstack-afterglow/openstack-afterglow/issues/new) から始めてください。韓国語と英語でのやり取りを歓迎します。翻訳の修正や言語追加も歓迎します。

## OpenStack への貢献

実運用から得た課題を、再現可能なバグ報告、修正、テスト、文書として OpenStack に還元することを目指しています。アップストリームへの変更は [OpenStack 公式貢献ガイド](https://docs.openstack.org/contributors/code-and-documentation/index.html) と対象プロジェクトの手順に従います。

Afterglow は独立して開発されています。この紹介は OpenStack 公式プロジェクトとしての認定、推奨、またはアップストリームでの採用を示すものではありません。
