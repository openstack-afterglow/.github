## 一起改善 OpenStack 的使用体验

Afterglow 是一个开发和管理 OpenStack 仪表板及配套服务的开源组织。核心项目 Afterglow 致力于成为 Horizon 和 Skyline 的替代选择，为云用户和运维人员提供现代化的统一界面。

Afterglow 已作为 [DMS Cloud](https://cloud.dmslab.re.kr) 控制台投入运行，并根据实际云环境的使用经验持续改进。在线服务的访问遵循运营方的账户和项目政策。

## 项目

| 项目 | 方向 |
| --- | --- |
| [Afterglow](https://github.com/openstack-afterglow/openstack-afterglow) | 基于 SvelteKit 和 FastAPI 的 OpenStack 资源管理与服务集成 |
| [Drover](https://github.com/openstack-afterglow/drover) | OpenStack 上的 K3s 集群与节点组生命周期管理 |
| [Palimpsest](https://github.com/openstack-afterglow/palimpsest) | 可复用的虚拟机环境、SquashFS 层和启动镜像 |
| [Lumen](https://github.com/openstack-afterglow/lumen) | AI 聊天、智能体执行、工具、记忆与用量管理 |
| [Waygate](https://github.com/openstack-afterglow/waygate) | 按项目管理的 WireGuard 网关与客户端配置 |

请查看各仓库的 README，了解安装步骤、支持环境、发布状态和许可证。不同组件的成熟度及部署状态可能不同。

## 参与贡献

欢迎开发者、运维人员、研究人员、设计师、文档作者和首次参与开源的贡献者。除了代码，也可以贡献无障碍改进、翻译、测试、问题复现和运维经验。

1. 选择感兴趣的仓库，阅读 README、架构说明和开发指引。
2. 查看已有 Issue 和 PR；较大的功能或行为变更应先通过 Issue 讨论。
3. Fork 仓库并创建分支，提交范围清晰的小改动，运行项目规定的检查，更新相关测试与文档。
4. 提交 PR，说明问题、改动和验证结果。界面改动请附截图。

报告问题时，请提供版本或提交号、环境、预期行为、实际行为和最小复现步骤。请移除凭据、令牌及用户数据。无需加入组织即可提交 Issue 或 PR。

不确定从哪里开始？请访问 [Afterglow Issues](https://github.com/openstack-afterglow/openstack-afterglow/issues/new)。欢迎使用韩语或英语交流，也欢迎改进翻译、添加语言。

## 回馈 OpenStack

我们希望将实际运行中发现的共性问题整理为可复现的缺陷报告、补丁、测试和文档，贡献给 OpenStack。上游变更应遵循 [OpenStack 官方贡献指南](https://docs.openstack.org/contributors/code-and-documentation/index.html) 及目标项目的流程。

Afterglow 是独立开发的项目。本页面不表示其已获得 OpenStack 官方项目身份、认可或上游接纳。
